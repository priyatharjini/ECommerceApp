# ECommerceApp

## 📌 Project Description
ECommerceApp is a Java-based desktop application developed using JDBC and MySQL. It demonstrates basic e-commerce functionalities such as managing products, users, and orders with database connectivity.

---

## 🚀 Features

- Add Products
- View Products
- Update Product Details
- Delete Products
- User Management
- Order Management
- MySQL Database Connectivity

---

## 🛠 Technologies Used

- MySQL
- Eclipse IDE

## 🔧 Requirements

- Java JDK 21
- Eclipse IDE
- MySQL Server
- MySQL Connector JAR

---

## ▶️ How to Run

1. Clone the repository.
2. Open the project in Eclipse.
3. Add the MySQL Connector JAR.
4. Create the MySQL database.
5. Update the database username and password in `DBConnection.java`.
6. Run `MainApp.java`.
